# Portfolio Landing Page

## About

This project is a personal portfolio landing page built with React.
It showcases my skills, projects, and contact information in a clean and modern interface.

The main goal of this project was to create a responsive, animated, and well-structured portfolio using modern frontend technologies and scalable architecture.

## Live Demo

https://github.com/masvel-dev/portfolio

## Tech Stack

* React (TSX)
* Tailwind CSS
* Framer Motion
* Feature-Sliced Design (FSD)
* Vite

## Features

* Responsive and adaptive layout
* Smooth scrolling navigation
* Contact form with validation and submission
* Animated UI elements (Framer Motion)
* Feature-Sliced Design (FSD) architecture
* Reusable UI components
* Custom React hooks
* Code splitting and performance optimization
* Conditional rendering for different screen sizes

## Project Structure

The project follows Feature-Sliced Design (FSD) architecture:

src/

* app
* pages
* widgets
* entities
* shared
